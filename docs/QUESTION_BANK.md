# 산업안전기사 문제은행 출처와 검수

## 실제 근거와 권리

- 원고: `scripts/concepts.json`의 120개 개념 문항과 `scripts/generate_bank.py`의 24개 계산 템플릿. 생성 결과는 `src/data/questions.json` 1,000개.
- 작성 근거: AI 일반 안전공학 지식과 문항 안에 명시한 수학·물리·집계 정의. 읽지 않은 교재·KOSHA 가이드를 외부 정답 근거로 인용하지 않는다.
- 시험 규칙만 Q-Net 종목 1431의 취득방법을 직접 확인했다. 그 문서는 개별 문제의 정답 증빙이나 세부 출제기준 전체 대조를 대신하지 않는다.
- sourceUrl은 이 작성·검수 이력 문서를 가리킨다. GitHub 링크 자체가 외부 전문가의 정답 검증이 아니다.
- 모든 문항 자체 제작, 연도·회차 null. 검증된 원문 기출·복원 0개. 민간 사이트 대량 복제 없음. 새 문항은 CC BY 4.0으로 표시하며 공용 은행 가져오기 권리는 각 자료별로 별도 확인해야 한다.

## 실제 검수 범위

1. 개념 120개는 AI가 문장·정답·오답 선택지를 다시 읽고, 일반 안전 원칙에 부합하는지 내부 검토했다. 정량 법령 기준이나 정확한 법조문을 주장하지 않는다. 외부 독립 검수와 같지 않다.
2. 계산 880개는 생성에 Python Decimal/ROUND_HALF_UP, 검증에는 별도 TypeScript 대수식·단위 변환 경로를 사용한다. 정답 번호·단위·동치 보기 1개·반올림 결과를 전부 검증한다. 생성기 함수를 테스트에서 부르지 않는다.
3. 개념 문항의 정규화 본문·보기와 모든 ID의 중복을 검사한다. 보기 순서가 바뀐 동일 문항도 가져오기에서 중복 처리한다. 의미 검토에서는 숫자 siblings를 같은 family로 명시하고 기계 응력/건설 접지압 등의 서로 다른 적용 조건을 구별했다. 의미상 완전한 독창성이나 시험 범위 전체를 보장하지 않는다.
4. 입력 조건·가정·식·단위·대입값·결과가 해설에 포함된다. 확률·환기·압력 문제의 단순화 가정과 법적 적합성 판정 제외를 문항에 명시했다. 숫자 보기는 같은 단위로 만들고 다른 수치를 보장한다.
5. 무작위 생성이 없고 원고 순서·family 순서·ID·조건이 고정돼 있다. 재실행 동일 해시를 확인한다. 기존 풀이 참조를 보존하려면 기존 ID의 의미를 바꾸지 말고 새 ID를 부여해야 한다.

외부 전문가 검수, 법령 전체 검수, 공식 세부 출제기준의 항목별 매핑과 실제 기출 난이도 비교는 미완료다. 숫자 테스트를 이 작업들의 완료 증거로 해석하지 않는다. 현재 은행은 기본 원리 반복 연습에 집중되어 실제 시험의 범위·빈도를 대표하지 않는다.

## 로컬 검수

가져온 문항은 항상 pending으로 등록되어 학습에서 제외된다. 사용자가 출처·권리·정답·해설·해당 연도/회차를 직접 확인한 뒤 근거 문구와 체크박스로 승인해야 한다. 로컬 승인은 기본 은행 수정이나 GitHub 게시가 아니며 새로운 기출 재배포 권리를 부여하지 않는다.
