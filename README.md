산업안전기사용 비공식 학습 앱입니다. React·TypeScript·Vite로 구현하며 서버·로그인·유료 API가 필요하지 않습니다.

전기기능사 CBT 기준 커밋 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`의 화면·학습·저장 코드를 재사용했습니다. 표준 스킬 v1.3.1 전체는 [.agents/skills/cbt-site-standard](.agents/skills/cbt-site-standard/SKILL.md)에 복사하고 [AGENTS.md](AGENTS.md)에 연결했습니다. 이전 AGENTS.md는 없었습니다. 전기기능사 문제 데이터는 사용하지 않았습니다.

## 시험 규칙

2026-10-21 Q-Net의 [산업안전기사 종목 1431](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=1431) → 기본정보 → 취득방법을 직접 확인했습니다. [확인한 문구·해시](docs/official-rules-evidence.json), [앱 설정](src/qualification.ts)을 함께 보관합니다.

객관식 4지선다, 과목당 30분으로 합계 180분입니다. 각 과목 100점 중 40점 이상 **동시에** 전과목 평균 60점 이상이어야 합격입니다. 각 20문항이므로 과목당 최소 8개 정답·전체 최소 72개 정답이 필요합니다. 미응답은 오답입니다. UI의 점수 반올림과 별개로 원값으로 합격을 판정합니다. 모의시험은 이 필기 규칙만 구현하며 실기시험은 제공하지 않습니다.

## 기능

- 실전 모의시험: 과목별 추출, 답안 변경·번호 이동, 북마크, 절대 종료 시각, 새로고침 복원, 만료 자동 제출·중복 방지, 과락·과목별 결과·전체 해설·오답 재학습.
- 랜덤 학습: 전체/과목 선택, 순회 내 ID 중복 방지, 즉시 채점, 정답률·연속 정답, 오답노트·북마크·학습 통계.
- 실전 답안 선택 후·랜덤 채점 후 Space로 다음 문제 이동. 마지막 시험 문항에서 자동 제출하지 않습니다. 입력창·메뉴·대화상자·수정키·IME·길게 누르기 보호.
- 모바일 메뉴는 작은 높이·가로 모드·글자 확대에서 독립 스크롤. 학습 기준/연도 선택과 상시 상단 면책 배너는 없습니다. 비공식 표시는 사이드바/푸터, 검수 범위는 문제은행과 문서에서 제공합니다. 실제 저장 오류 경고는 유지합니다.
- JSON/CSV 등록 양식·검색·상태 필터·페이지·정규화 중복 제거·전체 등록 원자성·검수 대기·사용자 근거 입력 승인·내보내기. 로컬 등록은 공용 은행에 게시되지 않습니다.

## 문제은행과 검수 범위

자체 제작 1,000개, 원문 기출 0개, 복원 0개입니다. 개념형 120개와 **24개 계산 유형 × 36~37개 조건 = 숫자 변형 880개**입니다. 독립 원고 유형은 개념 120개+계산 24개=144개이며 1,000개의 독립 개념이나 기출을 뜻하지 않습니다.

`reviewed`는 이 프로젝트의 **AI 작성 후 내부 문장·정답 검토와 자동 수치 검증**을 뜻합니다. 외부 전문가 검수·문항별 공식 출제기준 대조·법령 전 범위 검수는 미완료입니다. 시험 규칙의 공식 확인과 문제 정답의 외부 검증은 서로 다릅니다. 법령 수치 문제는 작성하지 않았고 실제 출제 범위·난이도를 완전히 재현한다고 주장하지 않습니다. 세부 내용은 [문제은행 문서](docs/QUESTION_BANK.md)에 있습니다. 공개 웹 기출의 재배포 권리를 가정하여 복제하지 않았습니다.

시험 추출은 과목마다 개념 문항/계산 family에 먼저 한 자리씩 배정하고 20개를 고릅니다. 각 과목에는 20개 개념과 4개 계산 family가 있어 기본 은행으로는 같은 family가 중복되지 않습니다. 개인 은행에서 그룹 수가 부족하면 남은 고유 ID로 보충합니다.

## 로컬 개발

Node.js 24.19.0 고정(`.node-version`), 엔진 최소 22.12.0. Python 3는 원고 재생성에만 사용합니다.

```bash
cd /workspace/Industrial-Safety-Engineer-CBT
npm ci --cache /tmp/industrial-cbt-npm-cache --no-audit --no-fund
npm run dev -- --port 5173 --strictPort
```

현재 체크아웃을 사용합니다. 클라우드 작업은 이미 격리되어 있으므로 별도 worktree를 만들 필요가 없습니다.

```bash
npm run check
# 일반 환경/CI: 테스트 도구와 맞는 브라우저 설치
npx playwright install --with-deps chromium
npm run test:e2e
# 이 클라우드 이미지에 이미 설치된 Chromium을 쓰는 경우
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
# 재현 가능한 자체 문제은행 재생성 (기존 src/data/questions.json 덮어씀)
python3 scripts/generate_bank.py
```

빌드 결과는 `dist/`에 생성합니다. 문제 데이터 청크는 캐시용으로 UI와 분리되어 있으며 대형 청크 경고는 오류가 아닙니다. [검증 보고서](docs/VERIFICATION.md)에 실제 실행 범위·제한을 기록합니다.

## 기록과 개인정보

저장 키 `industrial-safety-engineer-cbt:v1`을 사용해 같은 소유자의 다른 GitHub Pages 앱과 분리합니다. 최근 응답 5,000개·시험 30회를 보관하며 통계는 보관된 응답의 반복 풀이를 포함합니다. 진행 시험·연습·오답·북마크·로컬 문항도 브라우저에 저장합니다. JSON 백업 다운로드는 제공하지만 **백업 복원 UI는 없습니다**. 기록 손상 시 원본을 자동 덮어쓰지 않으며 백업·확인 후 초기화할 수 있습니다. 초기화는 기본 은행을 삭제하지 않습니다.

브라우저/기기/origin이 바뀌면 기록이 공유되지 않습니다. 시크릿·저장 제한·외부 블로그 iframe의 제3자 정책에 따라 저장이 막힐 수 있습니다. 같은 origin iframe의 키보드·저장·백업만 자동 검증하며 실제 블로그와 실기기는 별도 확인 대상입니다.

## GitHub Pages

기본 경로는 `/Industrial-Safety-Engineer-CBT/`, 공개 주소는 https://YunSangYeong.github.io/Industrial-Safety-Engineer-CBT/ 입니다. 이 주소의 실제 배포 상태는 검증 보고서에서 확인합니다.

`.github/workflows/pages.yml`은 push/PR에서 검증만 실행하고 `main`에 대한 `workflow_dispatch`에서 검증 성공 후 배포합니다. 자동 push 배포는 없습니다. 기본 정책은 사용자 최종 배포이며, 이번 요청은 에이전트에게 실제 배포까지 명시적으로 위임한 예외입니다.

향후 사용자가 직접 배포하려면 Settings → Pages → Source를 **GitHub Actions**로 설정한 후 Actions → **Test and deploy GitHub Pages** → **Run workflow**, 브랜치 `main`을 선택합니다. CLI는 `gh workflow run pages.yml --ref main`입니다. 배포 후 두 모드·새로고침·Space·작은 화면 메뉴·백업을 확인합니다. 기본 주소는 커밋 변경 뒤에도 동일하므로 블로그 iframe 주소를 매번 바꿀 필요가 없습니다.
